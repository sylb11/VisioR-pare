
# VisioRépare Suisse v1

App trilingue (FR/IT/DE) con frontend PWA e backend Express demo.

## Avvio locale
```bash
cp .env.example .env
npm install
npm start
# poi apri http://localhost:3000/language.html
```

## Deploy su Vercel
- Dashboard → New Project → Import (repo o cartella)
- Framework: **Other**
- Root: `/`
- `npm start` (runtime Node, serve la cartella `public/`)
- Dopo il deploy, apri: `/language.html`
